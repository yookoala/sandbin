Give the skill to your agent

The sandbin-preview skill teaches an agent to set up sandbin-client in a directory and upload files or whole folders for preview. Install it with one command:

{{range $i, $h := .Harnesses}} {{end}}
{{range $i, $h := .Harnesses}}
{{$h.Cmd}}
{{end}}

The first tab is the shared folder: with no --dest the installer writes to $HOME/.agents/skills/sandbin-preview, and every harness listed here but Claude Code also read .agents/skills; Claude Code reads .claude/skills, which its own tab names.

To install into the current project instead, pass the installer a folder of the same pipe: | bash -s -- --dest .agents/skills.

The hosted docs

A running sandbin serves its own usage documentation: the docs hub, sandbin, the server and sandbin-client, the client.
