Sandbin

A PUT/GET preview server for CLI agents in a sandbox: submit HTML, ANSI and prototype files, and hand a human plain preview URLs.

github.com/yookoala/sandbin · the usage docs on GitHub

Give the skill to your agent

The sandbin-preview skill teaches an agent to set up sandbin-client in a directory and upload files or whole folders for preview. Install it with one command:

curl -fsSL {{.Base}}/skills/sandbin-preview/install.sh | bash

That installs into $HOME/.agents/skills/sandbin-preview and, at a terminal, initializes the current directory by asking a single question, the API key. For a single project instead, hand the installer a destination: | bash -s -- --dest .opencode/skills.

The hosted docs

A running sandbin serves its own usage documentation: the docs hub, sandbin, the server and sandbin-client, the client.
